An invariant is a rule about the whole fleet: "no server runs a desktop", "no two hosts share an address".
`yen.invariants.<name>` gives [Datalog](/query/datalog/) rules over the fleet's facts, as data. A true `[ "bad" … ]` atom is a violation.


```nix title="modules/fleet.nix"
{ yen, lib, ... }:
{
  yen.kinds.fleet = {
    spawns.host = _: yen.host;
    sinks.out.reduce = yen.lib.reduce.merge;
  };
  yen.kinds.host.fields = {
    addr = lib.types.str;
    form = lib.types.enum [
      "server"
      "laptop"
    ];
  };

  yen.fleet.main = { };
  yen.host.web = {
    addr = "10.0.0.1";
    form = "server";
  };
  yen.host.db = {
    addr = "10.0.0.2";
    form = "server";
  };
  yen.host.thinkpad = {
    addr = "10.0.0.50";
    form = "laptop";
  };
  yen.aspects.desktop.at = s: (s.form or null) == "laptop";
  yen.aspects.postgres.at = yen.host.db;
  yen.flake = { out, ... }: out;
}
```

```nix title="modules/invariants.nix"
# Rules over `result.facts`, as data. A fact is a list: [ "kind" K ID ], [ "has" ASPECT ID ], [ "val" FIELD ID VALUE ], …
# A variable is { var = "X"; }; every string is a constant. A true [ "bad" … ] atom is a violation.
{ ... }:
let
  v = x: { var = x; };
in
{
  # no server runs a desktop
  yen.invariants.no-desktop-on-servers = [
    {
      head = [
        "bad"
        "desktop-on-server"
        (v "H")
      ];
      pos = [
        [
          "val"
          "form"
          (v "H")
          "server"
        ]
        [
          "has"
          "desktop"
          (v "H")
        ]
      ];
    }
  ];
  # no two hosts share an address: a rule across machines (`lt` keeps one of each pair)
  yen.invariants.unique-addr = [
    {
      head = [
        "bad"
        "same-addr"
        (v "A")
        (v "B")
      ];
      pos = [
        [
          "kind"
          "host"
          (v "A")
        ]
        [
          "kind"
          "host"
          (v "B")
        ]
        [
          "val"
          "addr"
          (v "A")
          (v "X")
        ]
        [
          "val"
          "addr"
          (v "B")
          (v "X")
        ]
        [
          "lt"
          (v "A")
          (v "B")
        ]
      ];
    }
  ];
}
```

A rule is `{ head; pos ? [ ]; neg ? [ ]; }`. An atom is a list `[ rel t… ]`. A term is a string, an int, a bool,
or a variable `{ var = "X"; }`: every string is a constant. `lt` and `neq` compare two bound terms. A relation you derive
(other than `bad`) is declared with its arity: `yen.relations.reach.arity = 2;`. The facts:


| Fact | Holds when |
|---|---|
| `[ "scope" ID ]`, `[ "kind" K ID ]` | a scope exists, and its kind |
| `[ "has" ASPECT ID ]` | the aspect is active at the scope |
| `[ "edge" SINK FROM TO ]` | an element is routed |
| `[ "val" FIELD ID VALUE ]` | a field has a string, int, bool or path value (a float, function or derivation is an `unencodable` error) |
| `[ "ref" FIELD ID KIND NAME ]` | a field refers to an instance |
| `[ "error" CODE FROM ]` | an error record |

This fleet holds:


```nix title="result"
{
  incomplete = [ ];
  invariants = [
    "no-desktop-on-servers"
    "unique-addr"
  ];
  ok = true;
  violations = [ ];
}
```

## A change that breaks two rules


```nix title="variants/mistakes.nix"
# A desktop on a server, and a new host with a copied address.
{ yen, ... }:
{
  yen.aspects.desktop.at = yen.host.web;
  yen.host.spare = {
    addr = "10.0.0.2";
    form = "server";
  };
}
```

```nix title="result"
{
  ok = false;
  violations = [
    [
      "bad"
      "desktop-on-server"
      "fleet:main/host:web"
    ]
    [
      "bad"
      "same-addr"
      "fleet:main/host:db"
      "fleet:main/host:spare"
    ]
  ];
}
```

`result.check.why atom` gives the rules that prove a violation. `whyNot` and `proof` work as in Datalog:


```nix title="result"
[
  {
    head = [
      "bad"
      "same-addr"
      "fleet:main/host:db"
      "fleet:main/host:spare"
    ];
    neg = [ ];
    pos = [
      [
        "kind"
        "host"
        "fleet:main/host:db"
      ]
      [
        "kind"
        "host"
        "fleet:main/host:spare"
      ]
      [
        "val"
        "addr"
        "fleet:main/host:db"
        "10.0.0.2"
      ]
      [
        "val"
        "addr"
        "fleet:main/host:spare"
        "10.0.0.2"
      ]
    ];
  }
]
```

:::caution[Incomplete is not a pass]
A `bad` atom on a cycle through `not` is undefined. It goes to `incomplete`, and `ok` is false.
:::

:::tip[Gate changes on it]
[Stage](/agents/stage/) evaluates a change and refuses it when it adds a violation. CI can fail on `check.ok == false`.
:::
