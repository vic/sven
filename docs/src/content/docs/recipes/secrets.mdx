yen never reads a secret. It plans which host gets which encrypted file, as data that a secrets tool
(agenix, sops-nix) reads. A secret is an instance of a data kind; its owners are host refs.


```nix title="modules/kinds.nix" {12-17}
# A secret is data: nothing spawns it. A host's `secrets` sink only takes secret refs.
{ yen, lib, ... }:
{
  yen.kinds.fleet = {
    spawns.host = _: yen.host;
    sinks.out.reduce = yen.lib.reduce.merge;
  };
  yen.kinds.secret.fields = {
    file = lib.types.str; # the encrypted file in the repo
    owners = yen.lib.is lib.isList; # host refs
  };
  yen.kinds.host.sinks.secrets = {
    reduce = yen.lib.reduce.set;
    of = yen.kinds.secret;
    # the plan a secrets tool reads: agenix, sops-nix, or your own
    out =
      { host, secrets, ... }:
      {
        secretsPlan.${host.name} = map (s: {
          inherit (s) name file;
          path = "/run/secrets/${s.name}";
        }) secrets;
      };
  };

  yen.fleet.main = { };
  yen.flake = { out, ... }: out;
}
```

```nix title="modules/data.nix"
{ yen, ... }:
{
  yen.host.web = { };
  yen.host.db = { };
  yen.secret.tls = {
    file = "secrets/tls.age";
    owners = [ yen.host.web ];
  };
  yen.secret.db-password = {
    file = "secrets/db-password.age";
    owners = [
      yen.host.web
      yen.host.db
    ];
  };
}
```

One component delivers each secret to its owners. Another reports secrets that nobody owns:


```nix title="modules/deliver.nix"
{ yen, lib, ... }:
let
  secrets.instances = yen.kinds.secret; # a tree request: every secret, with its data
in
{
  # each host gets the secrets that name it
  yen.aspects.deliver = {
    at = yen.kinds.host;
    cycle =
      { tree, scope, ... }:
      {
        tree = [ secrets ];
        secrets = lib.filter (s: lib.any (yen.lib.same scope) s.owners) (lib.head (tree.select secrets));
      };
  };
  # a secret that no host owns is an error, not a silent leftover
  yen.aspects.orphans = {
    at = yen.kinds.fleet;
    cycle =
      { tree, ... }:
      {
        tree = [ secrets ];
        errors = [
          (map (s: "secret ${s.name} (${s.file}) has no owner") (
            lib.filter (s: s.owners == [ ]) (lib.head (tree.select secrets))
          ))
        ]; # one element: the list
      };
  };
}
```

```nix title="result"
{
  db = [
    {
      file = "secrets/db-password.age";
      name = "db-password";
      path = "/run/secrets/db-password";
    }
  ];
  web = [
    {
      file = "secrets/db-password.age";

```

A secret that nobody owns is an error, and a fleet with an error gives no outputs (`flake` is `{ invalid-flake-errors = … }`, the reason):


```nix title="variants/orphan.nix"
# A secret nobody owns: the orphan check reports it, and the fleet gives no outputs.
{
  yen.secret.old-token = {
    file = "secrets/old-token.age";
    owners = [ ];
  };
}
```

```nix title="result"
{
  errors = [
    "secret old-token (secrets/old-token.age) has no owner"
  ];
  flake = {
    invalid-flake-errors = {
      errors = [
        {
          class = "fixable";
          code = "error";
          error = "secret old-token (secrets/old-token.age) has no owner";
          from = "fleet:main";
          path = [ ];
        }
      ];
      incomplete = [ ];
      violations = [ ];
    };
  };
}
```

## Refs, not names

The sink's `of` is the secret kind, so only a ref passes. A name is refused, with the scope and the aspect:


```nix title="variants/by-name.nix"
# A secret by name, not by ref: `of` refuses it.
{ yen, ... }:
{
  yen.aspects.shortcut = {
    at = yen.host.db;
    secrets = "tls";
  };
}
```

```nix title="result"
[
  "sink secrets: element of aspect shortcut from fleet:main/host:db fails `of`"
]
```

## Values no answer states

A field whose type is `yen.lib.secret t` is checked like `t`, and an aspect reads its value. No answer states it:
facts, `data`, `scopes`, error records, the RDF export and the seal give `sha256:<hash>` instead. A rule can still
compare two secrets, because equal values have equal hashes: "no two hosts share a token" is a rule.


:::tip[Guard who may read]
The plan is data, so a rule about it is a query. The [reference fleet](https://github.com/vic/yen/blob/main/templates/fleet/modules/kits/vars.nix)
adds shared and per-machine generators, a deploy plan, and a guard that refuses a secret read by the wrong host.
:::
