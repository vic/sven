Before you apply a change, stage it. `yen.lib.stage { base; change; rejected; grant; }` evaluates the fleet
without and with the change. Nothing is applied. `ok` is true only when nothing new is wrong.

The fleet is the one from [Invariants](/query/invariants/). A change is plain data, so an agent can write it as JSON:


```json title="changes/desktop-on-web.json"
{ "yen": { "aspects": { "desktop": { "at": [ { "kind": "host", "name": "web" } ] } } } }
```

```nix title="stage.nix"
# Stage a change file against the fleet. Nothing is applied.
#   nix eval --impure --json --file stage.nix --argstr change changes/desktop-on-web.json
{
  change,
  grant ? null, # where the change may reach: yen.lib.grant { scopes = [ … ]; }
  rejected ? [ ], # sha256 of changes refused before
  yen ? builtins.fetchTarball "https://github.com/vic/yen/archive/main.tar.gz",
  nixpkgs ? builtins.fetchTarball "https://nixos.org/channels/nixos-25.05/nixexprs.tar.xz",
  import-tree ? import (
    builtins.fetchTarball "https://github.com/denful/import-tree/archive/main.tar.gz"
  ),
}:
let
  base = {
    imports = [ (import-tree ./modules) ];
    _module.args = {
      lib = import "${nixpkgs}/lib";
    };
  };
  s = (import yen).lib.stage {
    inherit base grant rejected;
    change = builtins.fromJSON (builtins.readFile (./. + "/${change}"));
  };
in
removeAttrs s [ "render" ]
```

```sh frame="terminal"
nix eval --impure --json --file stage.nix --argstr change changes/desktop-on-web.json
```

```nix title="result"
      removed = [ ];
    };
    scopes = {
      added = [ ];
      removed = [ ];
    };
  };
  errors = [ ];
  incomplete = [ ];
  ok = false;
  refused = [ ];

```

The change makes `desktop` active at the server `web`, and breaks an invariant. The answer has the violation,
the diff (scopes, routed elements, active aspects) and the change's `sha`.

## Grants only narrow

`yen.lib.grant { scopes = [ id prefixes ]; sinks ? null; }` says where a change may reach. A prefix covers a scope
and the scopes under it, by path segment. `narrow g h` keeps what both allow. No function makes a grant wider.

Every yen module can read the whole fleet through `yen`, so a change that declares anything can reach every scope
and every sink. yen refuses each scope the grant does not cover, with `class = "authority"`: no edit by this
author can fix it. This is coarse, and it is sound: a value that one scope reads from another never escapes the grant.


```json title="changes/postgres-on-thinkpad.json"
{ "yen": { "aspects": { "postgres": { "at": [ { "kind": "host", "name": "thinkpad" } ] } } } }
```

```nix title="result"
[
  {
    class = "authority";
    code = "outside-grant";
    error = "the change can reach fleet:main, outside the grant";
    from = "stage";
    got = "fleet:main";
    path = [ ];
  }
  {
    class = "authority";
    code = "outside-grant";
    error = "the change can reach fleet:main/host:thinkpad, outside the grant";
    from = "stage";
    got = "fleet:main/host:thinkpad";
    path = [ ];
  }
  {
    class = "authority";
    code = "outside-grant";
    error = "the change can reach fleet:main/host:web, outside the grant";
    from = "stage";
    got = "fleet:main/host:web";
    path = [ ];
  }
]
```

## Rejected before

Pass the `sha` of changes refused before in `rejected`. The same change is refused again, whoever sends it:


```nix title="result"
[
  {
    class = "authority";
    code = "rejected";
    error = "this change was rejected before";
    from = "stage";
    got = "a1969acc86001f4528de7a4ec227f9cf7a5af809fd2555b04adeed0dd6c04146";
    path = [ ];
  }
]
```

## A change from Nix

`yen.lib.change.set path value` writes the same data from Nix: one declaration path gets one value.
This gives the change in `desktop-on-web.json`:


```nix
yen.lib.change.set [ "aspects" "desktop" "at" ] [ { kind = "host"; name = "web"; } ]
```

:::tip[Safe places for an aspect]
A stored query can stage an aspect on each machine and return where it is safe, and why the others are refused.
See `safeHostsFor` in the reference fleet's [agent/synthesis.nix](https://github.com/vic/yen/blob/main/templates/fleet/modules/agent/synthesis.nix).
:::
