`yen.lib.kits` holds kits written as modules, so a fleet writes only assemblies. A kit that reads public values
takes `{ root; }`, the directory of the vars. Battery `addresses` gives each member an address of a prefix, in
member order; a repeated address, a prefix that is no IPv4 /16 to /24 and a prefix too small are error records.

| Kit | Roles | Interface | Does |
|---|---|---|---|
| `wireguard { root; }` | `controller` (exactly 1), `peer` | `prefix`, `port` (51820) | an address per member; keys by generators; the private key is a path, never in the store; a peer talks to the controller |
| `zerotier { root; }` | `controller` (1), `moon` (0 to 4), `peer` | none | the controller's network id and the moons' ids are public generator files; peers join and list the moons |
| `dns` | `default` | none | a record for every `endpoints` any kit exports |

This is the fleet's own words, and the assemblies:


```nix title="modules/network.nix"
# Network kits shipped with yen: write only assemblies. `root` is where public keys and ids are read from.
{
  yen,
  lib,
  inputs,
  ...
}:
let
  inherit (yen) kit machine;
  inherit (yen.lib) same;
  root = ../vars/per-machine;
in
{
  imports = [
    (inputs.yen.lib.kits.wireguard { inherit root; })
    (inputs.yen.lib.kits.zerotier { inherit root; })
    inputs.yen.lib.kits.dns
  ];
  yen.machine = {
    lb.addr = "10.0.1.1";
    web.addr = "10.0.1.10";
    db.addr = "10.0.1.20";
  };

  # wireguard: lb is the hub, web and db are peers; addresses come from the prefix, in member order
  yen.assembly.vpn = {
    kit = kit.wireguard;
    roles = {
      controller = {
        at = machine.lb;
        settings.prefix = "10.8.0.0/24";
      };
      peer = {
        at = m: same m machine.web || same m machine.db;
        settings = {
          prefix = "10.8.0.0/24";
          port = 51821;
        };
      };
    };
  };
  # zerotier: one controller, up to four moons, any machine as a peer
  yen.assembly.lan = {
    kit = kit.zerotier;
    roles = {
      controller.at = machine.lb;
      moon.at = machine.web;
      peer.at = machine.db;
    };
  };

  # a kit that gives endpoints; dns reads them
  yen.kit.site = {
    roles.default = { };
    exports = [ "endpoints" ];
  };
  yen.assembly.site = {
    kit = kit.site;
    roles.default.at = machine.web;
  };
  yen.aspects.site = {
    at = yen.lib.all [
      yen.kinds.member
      (s: same (s.kit or null) kit.site)
    ];
    exports = {
      endpoints = [ "www.example.org" ];
    };
  };
}
```

## The contract

A wireguard or zerotier network needs exactly one controller, zerotier allows four moons at most, and a prefix
must hold its members.


```nix title="variants/five-moons.nix"
# zerotier allows four moons: five machines make five
{ yen, ... }:
{
  yen.machine = {
    m1.addr = "10.0.2.1";
    m2.addr = "10.0.2.2";
    m3.addr = "10.0.2.3";
    m4.addr = "10.0.2.4";
    m5.addr = "10.0.2.5";
  };
  yen.assembly.crowd = {
    kit = yen.kit.zerotier;
    roles = {
      controller.at = yen.machine.lb;
      moon.at = yen.kinds.machine;
    };
  };
}
```

The members of one wireguard assembly must name the same prefix, and every member needs its public file in
`vars`. A missing file is an error record, never a text in the configuration:


```nix title="variants/prefix-differs.nix"
# the members of one assembly name different prefixes
{ yen, ... }:
{
  yen.assembly.split = {
    kit = yen.kit.wireguard;
    roles = {
      controller = {
        at = yen.machine.lb;
        settings.prefix = "10.9.0.0/24";
      };
      peer = {
        at = yen.machine.web;
        settings.prefix = "10.9.1.0/24";
      };
    };
  };
}
```

```nix title="result"
[
  "wireguard: assembly split members disagree on prefix"
  "wireguard: lb has no wg-split.pub public key"
  "wireguard: web has no wg-split.pub public key"
]
```

```nix title="variants/missing-public.nix"
# a public key file that is not in vars is an error record, never the text "absent"
{ yen, ... }:
{
  yen.assembly.lost = {
    kit = yen.kit.wireguard;
    roles.controller = {
      at = yen.machine.lb;
      settings.prefix = "10.9.0.0/24";
    };
  };
}
```

