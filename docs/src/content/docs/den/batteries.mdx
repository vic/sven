A Den battery is an aspect that Den ships. You include it, sometimes with an argument:
`(den.batteries.user-shell "fish")`. In yen there is nothing to ship. The argument becomes a typed field of
the host or the user, and the battery is a short aspect whose `at` says where it applies.

The table lists every battery in Den's `modules/aspects/batteries/`. The count is how often each one appears in
the 20 most starred public Den configurations on GitHub (October 2026).


| Den battery | Uses | yen |
|---|---|---|
| `unfree [ … ]` | 41 | a sink of names and one predicate: [Unfree packages from many files](/nixos/unfree/) |
| `primary-user` | 30 | an aspect at the user: [From Den](/migrate/from-den/#batteries-are-aspects) |
| `define-user` | 27 | an aspect at every user: [From Den](/migrate/from-den/#batteries-are-aspects) |
| `hostname` | 25 | an aspect at every host, below |
| `forward` | 16 | a sink whose key gives to another sink: [Custom classes](/den/classes/) |
| `user-shell "fish"` | 11 | a `shell` field and one aspect, below |
| `inputs'`, `self'` | 21 | `inputs` is an arg of every yen module; per system: `inputs.x.packages.${pkgs.stdenv.hostPlatform.system}` |
| `flake-scope` | – | nothing: `yen`, `lib` and `inputs` are args of every yen module |
| `host-aspects` | 9 | an aspect at the users `within` the host that opt in: [includes and provides](/den/includes/) |
| `mutual-provider` | 6 | nothing: in Den it is inert; in yen `within` routes both ways |
| `tty-autologin "ana"`, `vm-autologin` | 7 | a host field that names a user, below |

| `home-manager` | – | an aspect where a host has users: [From Den](/migrate/from-den/) |
| `hjem`, `maid` | – | a user sink, chosen by a `classes` field: [den/custom-classes.nix](https://github.com/vic/yen/blob/main/templates/fleet/modules/den/custom-classes.nix) |

## Parameters are fields

`user-shell "fish"` and `tty-autologin "ana"` take an argument. In yen the argument is data on the instance,
with a type. A typo such as `shell = "fsh"` is an error at `yen.user.ana.shell`, and `autologin` must be a user
that exists.


```nix title="modules/fleet.nix"
# Den's schema, declared: hosts build NixOS and hold users. Battery parameters are typed fields.
{
  yen,
  lib,
  inputs,
  ...
}:
let
  inherit (yen.lib) opt maybe is;
in
{
  yen.kinds.fleet = {
    spawns.host = _: yen.host;
    sinks.out.reduce = yen.lib.reduce.merge;
  };
  yen.kinds.host = {
    fields.autologin = maybe yen.kinds.user; # den.batteries.tty-autologin "ana"
    spawns.user = s: lib.filterAttrs (_: u: lib.any (yen.lib.same s) u.hosts) yen.user;
    sinks.nixos.out =
      { host, nixos, ... }:
      {
        nixosConfigurations.${host.name} = inputs.nixpkgs.lib.nixosSystem { modules = nixos; };
      };
  };
  yen.kinds.user.fields = {
    hosts = is lib.isList;
    shell = opt (lib.types.enum [
      "bash"
      "zsh"
      "fish"
    ]) "bash"; # den.batteries.user-shell "fish"
  };

  yen.fleet.main = { };
  yen.flake = { out, ... }: out;

  yen.host.box.autologin = yen.user.ana;
  yen.user.ana = {
    hosts = [ yen.host.box ];
    shell = "fish";
  };
  yen.user.bob.hosts = [ yen.host.box ];
  yen.aspects.box = {
    at = yen.host.box;
    nixos = {
      boot.loader.grub.device = "nodev";
      fileSystems."/" = {
        device = "/dev/sda1";
        fsType = "ext4";
      };
      nixpkgs.hostPlatform = "x86_64-linux";
      system.stateVersion = "25.05";
    };
  };
}
```

```nix title="modules/batteries.nix"
# Den batteries as yen aspects. A battery's `includes` site becomes the aspect's `at`; its argument becomes a field.
{ yen, lib, ... }:
{
  # den.batteries.hostname
  yen.aspects.hostname = {
    at = yen.kinds.host;
    nixos =
      { host, ... }:
      {
        networking.hostName = host.name;
      };
  };

  # den.batteries.user-shell: the shell is the user's field
  yen.aspects.user-shell = {
    at = yen.kinds.user;
    nixos =
      { user, pkgs, ... }:
      {
        programs.${user.shell}.enable = lib.mkIf (user.shell != "bash") true;
        users.users.${user.name}.shell = pkgs.${user.shell};
      };
  };

  # den.batteries.tty-autologin: on the hosts that name a user
  yen.aspects.tty-autologin = {
    at = s: s.autologin or null != null;
    nixos =
      { host, ... }:
      {
        services.getty.autologinUser = host.autologin.name;
      };
  };

  # den.batteries.define-user, short
  yen.aspects.define-user = {
    at = yen.kinds.user;
    nixos =
      { user, ... }:
      {
        users.users.${user.name}.isNormalUser = true;
      };
  };

  # Den's `user` class (os-user): a user sink that writes users.users.<name>.
  # yen calls it `account`, because `user` is the arg that holds the user itself.
  # A sink with no elements gives nothing, so keep defaults out of it: they go in define-user.
  yen.kinds.user.sinks.account.nixos =
    { user, account, ... }:
    {
      users.users.${user.name} = lib.mkMerge account;
    };
  yen.aspects.ana-tools = {
    at = yen.user.ana;
    account = {
      description = "Ana";
      extraGroups = [ "wheel" ];
    };
  };
}
```

## Insecure packages need a sink too

`permittedInsecurePackages` is a list, but it is in `nixpkgs.config`, and `nixpkgs.config` does not merge lists.
When two NixOS modules set it, only one list survives, with no error. We wrote this page first without the
sink, on NixOS 25.05, and bob's entry was lost. The fix is the same as for `unfree`: a sink of names, and one
module that sets the option.


```nix title="modules/insecure.nix"
# den.batteries.insecure: nixpkgs.config does not merge lists. When two modules set permittedInsecurePackages,
# only one list survives. A sink collects the names, and one module sets the option.
{ yen, lib, ... }:
{
  yen.kinds.host.sinks.insecure.nixos =
    { insecure, ... }:
    {
      nixpkgs.config.permittedInsecurePackages = lib.flatten insecure;
    };

  yen.aspects.matrix-client = {
    at = yen.host.box;
    insecure = [ "olm-3.2.16" ];
  };
  yen.aspects.old-tool = {
    at = yen.user.bob; # from a user: the names go up to each of bob's hosts
    insecure = [ "python-2.7.18.8" ];
  };
}
```
