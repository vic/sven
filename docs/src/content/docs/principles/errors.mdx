yen never calls `throw`. When something is wrong, the read gives `null`, evaluation continues,
and the `errors` query lists a record. An empty list means the fleet is valid.

## Error records

Each record has `error` and `from` for people, and `code`, `path`, `got`, `want`, `fix`, `class` and `near`
for tools and agents. `class` is `fixable` when an edit to the data fixes it, and `authority` when no edit
by this author can.


```nix title="variants/typo.nix"
{ yen, ... }:
{
  yen.host.cache = {
    addr = "10.0.0.5";
    bakup = false;
  };
}
```

```nix title="result"
[
  {
    class = "fixable";
    code = "unknown-field";
    error = "unknown field bakup";
    fix = "declare yen.kinds.host.fields.bakup, or use a declared field";
    from = "host:cache";
    near = [
      "backup"
    ];
    path = [
      "bakup"
    ];
  }
]
```

## Your own checks

An aspect key `errors` gives records, or plain messages. yen sets `from` to the scope that gave it: an aspect cannot
report for another scope. A record without `class` is `fixable`.
Here `unique-addr` checks that no two hosts share an address:


```nix title="modules/fleet.nix"
{ yen, lib, ... }:
{
  yen.kinds.fleet = {
    spawns.host = _: yen.host;
    sinks.out.reduce = yen.lib.reduce.merge;
    sinks.warnings.out =
      { warnings, ... }:
      {
        inherit warnings;
      }; # messages that do not fail the fleet
  };
  yen.kinds.host.fields = {
    addr = lib.types.str;
    backup = yen.lib.opt lib.types.bool true;
  };

  yen.fleet.main = { };
  yen.host.web.addr = "10.0.0.1";
  yen.host.db.addr = "10.0.0.2";
  yen.host.scratch = {
    addr = "10.0.0.9";
    backup = false;
  };
  yen.flake = { out, ... }: out;
}
```

```nix title="modules/checks.nix" {9-15}
# An aspect key `errors` gives error records, or plain messages. Nothing throws. `from` is always the giving scope.
{ yen, lib, ... }:
let
  hosts.instances = yen.kinds.host; # a tree request: every host, with its data
in
{
  yen.aspects.unique-addr = {
    at = yen.kinds.fleet;
    cycle =
      { tree, ... }:
      {
        tree = [ hosts ];
        errors = [
          (lib.concatLists (
            lib.mapAttrsToList (
              a: hs:
              lib.optional (lib.length hs > 1) {
                code = "duplicate-addr";
                error = "${a} is the address of ${lib.concatMapStringsSep " and " (h: h.name) hs}";
                fix = "give each host its own addr";
                path = [ "addr" ];
                got = a;
              }
            ) (lib.groupBy (h: h.addr) (lib.head (tree.select hosts)))
          ))
        ];
      };
  };
  yen.aspects.no-backup = {
    at = yen.lib.all [
      yen.kinds.host
      (s: !s.backup)
    ];
    warnings = { host, ... }: "${host.name} has no backup";
  };
}
```

A new host with the address of `web` gives an error record:


```nix title="variants/duplicate.nix"
# A second host with the address of web. The `unique-addr` check reports it, and the fleet gives no outputs.
{
  yen.host.cache.addr = "10.0.0.1";
}
```

```nix title="result"
[
  {
    class = "fixable";
    code = "duplicate-addr";
    error = "10.0.0.1 is the address of cache and web";
    fix = "give each host its own addr";
    from = "fleet:main";
    got = "10.0.0.1";
    path = [
      "addr"
    ];
  }
]
```

A fleet with an error gives no outputs. Its `flake` is `{ invalid-flake-errors = { errors; violations; incomplete; }; }`
until `errors` is `[ ]` and every invariant holds: a build finds no output, and `nix eval .#invalid-flake-errors`
tells you, or an agent, why:


```nix title="result"
{
  invalid-flake-errors = {
    errors = [
      {
        class = "fixable";
        code = "duplicate-addr";
        error = "10.0.0.1 is the address of cache and web";
        fix = "give each host its own addr";
        from = "fleet:main";
        got = "10.0.0.1";
        path = [
          "addr"
        ];
      }
    ];
    incomplete = [ ];
    violations = [ ];
  };
}
```

## Warnings

A warning is a message that does not fail the fleet. It is a plain sink with `list` reduce, here given
to the flake as `warnings`:


```nix title="result"
[
  "scratch has no backup"
]
```

:::tip[Gate CI on it]
In CI, fail when `errors` is not `[ ]`, before any build. A `query.nix` gives every query on the command line:
see [Project layout](/start/project-layout/).
:::
